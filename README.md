# Blog HTML e CSS - Semana 02

Projeto desenvolvido como entregável da Semana 02 da disciplina de Desenvolvimento Web.

## Objetivo

Dar continuidade ao blog desenvolvido na Semana 01, aplicando CSS ao formulário de inscrição para melhorar sua organização, aparência e usabilidade.

## Tecnologias utilizadas

- HTML5
- CSS3
- Flexbox

## Funcionalidades

O projeto possui:

- estrutura semântica utilizando HTML5;
- menu de navegação;
- dois artigos;
- formulário de inscrição;
- validação de nome, e-mail e idade;
- seleção de assunto;
- checkbox obrigatório para aceite dos termos;
- formulário organizado utilizando Flexbox;
- campos de nome e e-mail lado a lado;
- layout responsivo;
- botão estilizado com efeito `hover`.

## Conceitos CSS aplicados

Foram utilizados:

- `max-width`;
- `padding`;
- `background-color`;
- `display: flex`;
- `flex-direction`;
- `gap`;
- `justify-content`;
- `border`;
- `border-radius`;
- `font-size`;
- `cursor: pointer`;
- pseudo-classe `:hover`;
- media queries para responsividade.

## Como executar

1. Clone ou baixe o repositório.
2. Abra o projeto no Visual Studio Code.
3. Abra o arquivo `index.html`.

Também é possível utilizar a extensão Live Server para visualizar as alterações em tempo real.
